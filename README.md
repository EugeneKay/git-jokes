git-jokes
=========

A collection of questionably humorous git sayings.

`git-jokes` was started as a project for the #git IRC channel on the Freenode IRC Network. A new joke was written for the channel's topic each day. Being funny on a continuous basis quickly becomes impossible, so jokes started to get reused. This repo contains a list of (most of) these funnies, in an easy-to-digest form.

There is also a git plugin, so you can now type `git joke` and receive a random joke! To use this, add the git-joke script from this repository somewhere on your $PATH. For example, you could `wget https://raw.githubusercontent.com/EugeneKay/git-jokes/lulz/git-joke`
into /usr/local/bin. Remember to verify the scripts' contents, and run `chmod +x git-joke` to make it executable by git.
